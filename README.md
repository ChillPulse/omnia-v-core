# OMNIA Flagship Streamer & Studio DSP — проект 24-Bit Direct

Монорепозиторий ESP32-S3 (ESP-IDF, PlatformIO) и WeAct AT32F403A (PlatformIO, at32firmlib): цифровой тракт, DSP и протокол управления. [Техническое задание](docs/OMNIA_MASTER_SPEC_v2.0.md) описывает также **планируемые**, а не только работающие функции.

> **Начинайте с [пошагового руководства](docs/START_HERE_RU.md) и [схемы стенда](docs/OMNIA_WIRING_STAGE1_CORE.png).** Прошивки и утилита ещё не проверены на вашей аппаратуре. Не подключайте усилитель, K2 и динамики. Принцип управления усилителем не является монтажной схемой. Сервисное меню, дисплей, ИК-обучение, приложения, PWA и большинство функций медиаплеера пока не готовы. Bluetooth отложен до фото; код Bluetooth и USB Audio по умолчанию выключен. Автоматического изменения USD/option bytes больше нет.

## Предусмотренная архитектура

- 24-битные данные в 32-битных I²S-слотах: ESP32 GPIO5 → AT32 PB14, DSP на AT32, PB15 → PCM5102A. Требуется проверка реального тайминга и формата.
- Два независимых USB-интерфейса: ESP32 GPIO19/20 — планируемый Host (ещё не реализован); AT32 PA11/PA12 — проект USB Audio UAC1 44,1/48 кГц (выключен до проверки). Автопереключение источника через PB9 VBUS/SOF — экспериментальная функция, не гарантия работы с каждым устройством.
- PB0 — DAC XSMT; PB2 — управление драйвером K2 питания усилителя; PB4 — Mute усилителя; PB8 — **опциональное** сигнальное реле K1. [Ограничения и смысл реле](docs/AMP_CONTROL_SAFETY.md).
- VS1838B: питание от 3,3 В, OUT → ESP32 GPIO40, GND общий; IR-обучение ещё предстоит реализовать.
- [Руководство SJR-BTM334](docs/SJR_BTM334_QCC3034_GUIDE.md): осторожно, даташиты разных ревизий противоречат друг другу по именам выводов 23/24; **контакт 21 в V1.3 — GND**.

## Частота

Рекомендация: нативные 44,1/48 кГц — основной режим без принудительного апсемплинга. Нативные 88,2/96 кГц можно рассмотреть позже для Hi-Res после измерения нагрузки, памяти и проверки аппаратных тактов; 96 кГц не является подтверждённым рабочим режимом текущей системы.

## Сборка и тесты

В VS Code открыть папку проекта и выбрать окружение PlatformIO:

```sh
pio run -e at32f403_dsp
pio run -e esp32s3_omnia
```

Локальный тест DSP и протокола на компьютере:

```sh
gcc -O2 -Wall -Wextra -Werror -Ishared -Isrc/at32/include \
  tests/test_dsp_and_proto.c src/at32/dsp_engine.c src/at32/asrc_farrow.c -lm -o /tmp/omnia-tests
/tmp/omnia-tests
```

Тесты на компьютере не подтверждают электрическую безопасность, бесщёлчковость, совместимость USB/Bluetooth и работу реального оборудования. Артефакты CI — экспериментальные, не для немедленного подключения усилителя.
