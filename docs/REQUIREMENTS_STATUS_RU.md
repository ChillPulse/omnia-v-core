# OMNIA — единый сводный статус требований

Единственный эталон требований — [OMNIA_MASTER_SPEC_v2.0.md](OMNIA_MASTER_SPEC_v2.0.md) (ТЗ v2.4, fw 2.4.0).
Этот файл отвечает только на вопрос **«где что из этого уже реально сделано и чем это подтверждено»**.
История решений и разбор исторических расхождений — в [docs/archive/](archive/README.md) (не применять как требования).
История изменений — [CHANGELOG.md](../CHANGELOG.md); модель конкурентности — [CONCURRENCY_MODEL_RU.md](CONCURRENCY_MODEL_RU.md).

**Правила чтения:**
- При расхождении ТЗ и этого файла приоритет — ТЗ (требование) но не статус (факт).
- При расхождении этого файла и измерений на железе приоритет — **измерения**; этот файл обновляется после испытаний.
- «HOST» означает: код есть, хост-тесты зелёные (в т.ч. `tests/test_dsp_quality.c`), сборка обоих МК зелёная в CI. Это **не** испытание аппаратуры и не проверка звука.
- «ЦЕЛЬ» означает: записано в ТЗ, кода/испытаний нет или функция выключена.

Статусы: **HOST** = реализовано + хост-проверено · **ЧАСТИЧНО** = реализовано неполно/с оговорками · **ЦЕЛЬ** = не реализовано · **ОТЛОЖЕНО** = нельзя/нельзя начинать · **ЖЕЛЕЗО?** = код есть, аппаратно не измерено.

## DSP-тракт (AT32)

| Требование (ТЗ §) | Статус | Чем подтверждено / чего нет |
|---|---|---|
| Bit-Perfect Direct (0.2 §3; `active_mask==0 && vol==0 dB`) | HOST | Побитовая копия int32 покрыта тестами; лимитер/DC-guard в этом режиме **не** работают — строгая трактовка bit-perfect (зафиксировано в ТЗ-комментарии и коде) |
| Subsonic HPF (§4) | HOST | Двухполевой biquad 15–40 Гц, Q 0.1–18; устойчивость полюсов проверена в quality-suite (1120 точек, r<1.0) |
| Headroom (§4) | HOST | как выше |
| Room PEQ 5 полос + delay/phase/trim (§4.2; `OMNIA_CMD_LOAD_ROOM_PEQ 0x11`, блок `BIT_ROOM_DELAY 1<<9`) | HOST | Задержки через Catmull-Rom (тест HF-плоскости 10 кГц); отдельный бит блока добавлен в fw 2.3.0. Фазовый реверс/полярность — HOST |
| PEQ: бесщёлчный ретюн активных звеньев (рампа коэффициентов, fw 2.4.0) | HOST | `tests/test_dsp_quality.c` тест 14: ретюн 1 кГц Q=4, −15 дБ → 700 Гц, +12 дБ — max |Δ| за 16 отсчётов ramp 0.0124 vs instant 0.0496 (в 4× плавнее). Bypass→enable/disable — мгновенно (блок-граница атомарна), рампа только для живого ретюна. На железе не измерено |
| Limiter: детектор true-peak (fw 2.4.0) | ЧАСТИЧНО | Кубическая (Catmull-Rom) оценка межсэмплового максимума с аналитическим поиском экстремумов производной; тест 15: 12 кГц, π/8, −0.8 dBFS скрытый пик → TP-ветка снижает gain (min_limiter_gain 0.9844). **НЕ полифазный 4× oversampling**; после ЦАП на железе не измерено |
| Анти-прыжок механического энкодера (shared/omnia_encoder.h, fw 2.4.0) | HOST | Host-тесты `tests/test_encoder.c`: декодер 4-битных окон (двухбитный скачок брака игнорируется, `illegal_events`++), интегратор дребезга 3 опроса, лимит скорости 1 мс/детент, фазовый накопитель 4×. **В ESP32 не подключён** (GPIO/механика не определены); константы не калиброваны под конкретный EC11; на железе не проверено |
| Интерактивный стендовый чек-лист (docs/OMNIA_BRINGUP_INTERACTIVE_RU.html) | HOST | jsdom-прогон: рендер 13 этапов/44 пунктов, поля измерено/прибор/коммит, localStorage, экспорт JSON, печать; без ошибок. Markdown-оригиналы остаются эталоном |
| User PEQ 10 полос (§4.2; `0x12`) | HOST | Коэффициенты от валидации; фейда коэффициентов нет (переключение щелчком теоретически возможно — не измерено) |
| Anti-Ad AGC (§4.5; `0x13`) | HOST | Envelope-детектор, тесты АЧХ/атаки/удержания; «Anti-Ad 2.0» как маркетинговое поведение — цель |
| VBB — психоакустический бас (§4.6; `0x14`) | HOST | Режим 0 — настоящая Low-Shelf @105 Гц; режимы 1/2 — асимметричные гармоники (LP гармоник, HP постоянки); спектральные проверки Гоерцеля в quality-suite; **звучание на НЧ-полосе аппаратуры не измерено** |
| AETHER Studio (§4.7; `0x15`) | HOST | 12 параметров + Sub-Bass Mono Lock (честный ФВЧ 2-го порядка, −32 дБ @40/250 Гц), crossfeed Bauer 260 мкс (кольцевой буфер +32 отсчёта), all-pass декорреляция, triode, deharsh; заводские пресеты 0–6 (`0x1B`). Identity в bypass: 0 int32-LSB. **Субъективная "шелковистость" — цель, не измерена** |
| Dynamic Loudness ISO 226 (§8; `0x16`) | HOST | Проверена ISO-226-аппроксимация и границы потолков; громкостно-зависимое поведение на железе не слушалось |
| Look-Ahead Limiter (§4.9; `0x17`) | ЧАСТИЧНО | Envelope + hard clamp по look-ahead буферу; с fw 2.4.0 детектор учитывает **кубическую оценку межсэмплового пика** (Catmull-Rom, аналитические экстремумы; тест 15), но это **НЕ полифазный 4× oversampling** и не TPDF 4×; default on в factory mask; на железе не измерено |
| DC Guard (защита от постоянки + `0x1A` RESET_DC_FAULT) | HOST | Защёлка при |DC| > 0.35 FS, выход в ноль, сброс только командой 0x1A; trip+reset покрыты тестами; **порог на реальном PCM5102 не измерялся** |
| A/B Instant Compare (`0x06`) | HOST | Команда обрабатывается; слышимость переключения без щелчков — не измерена |
| ReplayGain −18…+6 дБ (§5) | HOST | Диапазон валидирован (`omnia_limits.h`); metadata-парсеры FLAC/Vorbis — цель |
| Сжатие/утечки float→int32 | HOST | Насыщение в double (`float_to_i32_sat`), независимый TPDF-дизер L/R |
| Устойчивость биквадов (все секции) | HOST | Полюса r<1.0 в 1120 точках (quality-suite) |
| Процессорная нагрузка «~27%» (§0.2) | ЦЕЛЬ | Расчётная оценка, на устройстве не профилировалась |
| Смена Fs 44.1↔48 (§0.2 §3) | ОТЛОЖЕНО | Авто-мат в ESP намеренно отключён (`return ESP_ERR_NOT_SUPPORTED`); нужен проверенный mute-handshake + измеренный тест щелчков |

## Открытые противоречия и договорённости (перенесено из аудитов)

1. **15 User PEQ (исходное ТЗ) ↔ 10 User + 5 Room (улучшенное ТЗ).** Сохраняется 10 + 5; 15 User — не утверждено автоматически; нужна оценка CPU/Flash/протокола. (AUD-001-архив см. archive/REQUIREMENTS_AUDIT_RU.md)
2. **192 кГц** — не обещано и не является целью MVP; 88.2/96 — фаза 2 после измерений. (AUD-002)
3. **«~0% CPU/трафика» PWA** — трактовать как минимизацию, не буквальный ноль (TLS, синхронизация, кэш).
4. **«~27% нагрузка DSP»** — расчёт, не измерение.
5. **A/B RMS-баланс** — выравнивание до ±2.5 дБ, не идеал.
6. **True-peak** не реализован; лимитер envelope+clamp.
7. **Bit-perfect vs безопасность:** в bypass лимитер/DC-guard не работают — осознанный выбор (строгость bit-perfect). Factory mask по умолчанию — `SUBSONIC_HPF | LIMITER`.
8. **v2.2 → v2.3:** добавлены 0x1A/0x1B, `BIT_ROOM_DELAY`, `omnia_limits.h`, fw 2.3.0; см. [CHANGELOG.md](../CHANGELOG.md).
9. **v2.3 → v2.4:** fw 2.4.0 — PEQ-рампа коэффициентов активных звеньев, true-peak оценка (кубическая, не 4×), git-derived диагностика сборки (`omnia_fw_version.h` + `pio_fw_version.py`), cppcheck 2.22.0 в CI, `shared/omnia_encoder.h` (хост-тесты, в ESP32 не подключён), интерактивный чек-лист; см. [CHANGELOG.md](../CHANGELOG.md).
