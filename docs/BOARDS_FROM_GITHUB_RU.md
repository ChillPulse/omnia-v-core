# Платы и модули: сверка старого GitHub-ТЗ с текущим проектом

**Назначение:** не менять улучшенное ТЗ и не восстанавливать старую архитектуру, а использовать ранее записанные в проектном репозитории данные о платах и модулях. Пользователь уже сообщал модели, повторно запрашивать их не требуется. Этот перечень — первый сопоставительный проход по аппаратным разделам, не окончательная монтажная спецификация.

## Источники и порядок применения

1. **Текущая рабочая версия:** [Master Spec v2.4](OMNIA_MASTER_SPEC_v2.0.md), проектные сети в `CORE_SIGNAL_NETS_RU.md`, карта в `KNOWN_BOARD_BASELINE_RU.md` и дальнейшие решения пользователя. Она остаётся основой проекта.
2. **Старое проектное ТЗ на GitHub — образец именно для данных об оборудовании:** файл `docs/OMNIA_MASTER_SPEC_v2.0.md` репозитория `ChillPulse/omnia-v-core`, две последние ранее проверенные опубликованные версии: [`main` 7ab8b0c](https://github.com/ChillPulse/omnia-v-core/blob/7ab8b0c673693010c02b27d0cd2289552cf89424/docs/OMNIA_MASTER_SPEC_v2.0.md) и [`wip/v2.2-direct-safety` ffc6859](https://github.com/ChillPulse/omnia-v-core/blob/ffc6859b704517059f4d124fd57371301cbfa2b7/docs/OMNIA_MASTER_SPEC_v2.0.md). Сохранены точные копии: [main](reference/OMNIA_MASTER_GITHUB_MAIN_7ab8b0c.md), SHA-256 `32e430f226557dce731616d407bc5de58ab88d619bc9847948a15ae1a21e2661`; [WIP](reference/OMNIA_MASTER_GITHUB_WIP_ffc6859.md), SHA-256 `6226655b0381b24decb1e9110946de0ea73b3b4b090bdccbd30772c97bc1f2e1`. Версии взяты из локальной Git-истории, соответствующей ранее проверенным ссылкам на удалённые ветки; повторной проверки удалённого состояния сейчас не проводилось.
3. Документ из `ChillPulse/Info-spravka` — более ранний концепт, **не тот основной образец оборудования**, на который указал пользователь. Оставлен как дополнительный исторический источник, но не как основание пересматривать согласованные функциональные требования.
4. Старые проектные схемы, GPIO и заявления о готовности проверяются относительно текущих решений, официальной схемы соответствующей платы и измерений. Найденное в старом ТЗ ≠ автоматически подтверждённая распиновка экземпляра или разрешение на пайку. BT — отложен до фото.

## Что ещё остаётся

Сверить оставшиеся детали плат/компонентов во всём старом проектном ТЗ и других исторических файлах с текущим BOM и последующими решениями, не заменяя функциональное ТЗ. Отдельно проверить схемы, напряжения, защиту, соединения и реальные перемычки. История и данные плат не равны результатам физической проверки.
