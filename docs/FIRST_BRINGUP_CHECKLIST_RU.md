# Первый запуск OMNIA: краткий чек-лист

**Только стенд, не готовое изделие.** Начинать можно с каждой платы отдельно; не подключать УМЗЧ, K1/K2, динамики, 230 В, TFT, Bluetooth, USB Host или DAC до идентификации и отдельного разрешения на соответствующий этап. Полная инструкция — [START_HERE_RU.md](START_HERE_RU.md).

## 0. Определить оборудование и исходники

- [ ] Указать ОС компьютера и чем собирается проект (VS Code + PlatformIO).
- [x] Взять за основу ESP32 YD-ESP32-S3 по присланной распиновке, WeAct AT32F403ACGU7, фиолетовый GY-PCM5102 и имеющийся клон ST-Link. Источники и особенности — [аппаратная база](KNOWN_BOARD_BASELINE_RU.md). Повторно запрашивать фото AT32 и распиновку не требуется.
- [ ] Перед конкретной физической операцией уточнить по доступным приборам питание и способ проверки, без предположений о выводах клона ST-Link.
- [ ] Выяснить, сохранять ли заводскую прошивку и данные плат. Прошивка может перезаписать Flash, а изменение опций — затронуть защиту и данные.
- [ ] Открыть **текущие локальные исходники** в VS Code. Если GitHub отстаёт, использовать архив, подготовленный в этой беседе; убедиться в названной версии. Не предполагать, что клон `main` или старый WIP содержит новые коммиты.
- [ ] Собрать оба окружения `pio run -e esp32s3_omnia` и `pio run -e at32f403_dsp`. Сборка не прошивает устройства.

## 1. ESP32-S3 отдельно

- [ ] При выключенном питании оставить ESP32 без внешних соединений; мультиметром проверить питание/землю на грубые короткие замыкания, если прибор есть. Не выводить 5 В на сигнальные GPIO.
- [ ] После определения USB-порта на конкретной плате подключить кабель данных к штатному порту программирования. Питание только штатным, проверенным способом; наблюдать нагрев и ток, при неисправности сразу отключить.
- [ ] С учётом необходимости резервной копии и подтверждения порта выполнить `pio run -e esp32s3_omnia -t upload`; затем `pio device monitor -e esp32s3_omnia` (115200 бод).
- [ ] Сохранить первые строки загрузки и ошибки; отсутствие AT32 в логах нормально. PSRAM и NVS нужно проверить по логам, не стирая Flash наугад. Закрыть монитор перед повторной прошивкой.

## 2. AT32 отдельно

- [ ] Опознать точную плату, программатор, питание и выводы SWD. Подключать после подтверждения конкретного программатора; `Vref` может быть входом измерения и не обязательно питает плату.
- [ ] Считать и сохранить USD/option bytes и нужную старую прошивку штатным поддерживаемым инструментом. Пока данных нет, **не стирать USD и не менять EOPB0 наугад**.
- [ ] Проверить настройки по официальной Artery AN0026 и [основной инструкции](START_HERE_RU.md); для данной прошивки требуется подтверждённый режим 224 КиБ. Не уверены в утилите/последствиях — остановиться и прислать фото/скриншот, исключив секреты.
- [ ] Только после определения программатора и проверки питания настроить правильный `upload_protocol` и прошить AT32. Проверить реакцию и отдельно диагностировать UART 3,3 В, если он есть.

## 3. Связь плат — не первый шаг

Сначала обе платы должны отдельно проходить этапы выше. Потом при снятом питании и после определения способов питания можно перейти к общей земле и UART, а затем к I²S в [основной инструкции](START_HERE_RU.md). Не объединять 5-вольтовые выходы источников; проверить отсутствие обратного питания через сигнальные линии. Схематичный рисунок сигналов не показывает физическую ориентацию разъёмов и не подтверждает распиновку клона.

До подключения GY-PCM5102 нужны проверка перемычек, регулятора питания, XSMT и SCK по маркировке и прозвонкой; фото не являются обязательным условием. ЦАП — линейный выход, не выход для динамиков. Bluetooth отложен до отдельной фотографии модуля.
