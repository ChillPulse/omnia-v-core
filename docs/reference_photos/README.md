# Справочные фото плат

Материалы, присланные пользователем. Это **справочные изображения, а не проверенные монтажные схемы** конкретной ревизии плат.

- `ESP32_YD_pinout_reference.jpeg` — типовая распиновка клона ESP32-S3 N16R8 (VCC-GND Studio / «YD»). Это **справочный рисунок, а не фото вашей платы**. Учесть: GPIO35–37 заняты octal PSRAM; GPIO19/20 связаны со встроенным native USB-C; GPIO48 — встроенный RGB; GPIO0/3/45/46 — strapping.
- `TFT_134233.jpg`, `TFT_134251.jpg`, `TFT_134306.jpg` — фото дисплея TENSTAR ROBOT 2.8" ST7789 (три ракурса).

Перед пайкой/перепайкой сверить обозначения и поряддок выводов на конкретной плате. Старые рисунки переделки дисплея лежат в `docs/archive/` и не являются руководством к пайке.
