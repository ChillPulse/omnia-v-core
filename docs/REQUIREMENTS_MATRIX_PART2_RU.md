## Исходные данные 7-кнопочной лестницы (не монтажная схема)

В оригинале строки 69–79: подтяжка к 3,3 В через 1 кОм, отдельные кнопки с резисторами на землю 0 / 1 / 2,2 / 3,3 / 4,7 / 6,8 / 10 кОм, соответственно Power / Mute / Source / Favorite / Prev / Next / Play, с допуском 1%. Это сохранённая спецификация для анализа, а не подтверждение допустимости номиналов, точности или работы АЦП ESP32-S3. Нужны диапазоны ADC с допусками, воздействие нажатия нескольких кнопок, расчёт токов и помех, устойчивые пороги и испытания. Исходная заявленная «защита от дребезга» одними резисторами не доказана.

Далее остаются строки 126–1371, остальные требования и вся сквозная сверка с последующими решениями и исходным кодом.
